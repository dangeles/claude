# Fact-checking

Check what the argument leans on. Don't build a verification bureaucracy around it.

## What to check

Verify a claim when the essay's point depends on it being true, or when it's specific enough
to be wrong: numbers, dates, named studies, "researchers found," attributions of position to
a person or field.

Skip: interpretation ("this is a paradigm shift"), the user's own experience, value
judgments, and things any reader already knows ("DNA encodes genetic information").

Rule of thumb — if a reader could check it and catch you out, check it first.

## How

Batch a section's claims into one essay-fact-checker invocation. Give it the claims and
enough context to know what they mean. It returns verification status and source URLs.

Prefer primary sources over reporting about them: the paper, not the press release; the
agency's own statistics, not a news summary. Peer-reviewed work beats preprints, and
preprints should be labeled as not yet reviewed. If a news article cites a study, cite the
study.

## When it doesn't verify

Three honest options, in rough order of preference: revise the claim to match what's
actually established, hedge it in the text so the reader knows the ground is soft
("estimates range from X to Y," "one 2019 study suggested"), or cut it.

There is no deferred-claims queue. If you couldn't verify something, note it in one line
where it appears in the draft, and resolve it before the essay ships. If the user wants to
keep an unverified claim, say so once and respect the decision — it's their essay and their
name on it.

## When sources disagree

Report the disagreement rather than picking a winner silently. Check whether one is more
recent, one is primary and the other secondary, or they're measuring different things that
only appear to conflict. Genuine scientific disagreement is interesting material — "the
field doesn't agree about this, and here's why" is often a better paragraph than either side
alone.

## Research to strengthen an argument

The fact-checker can also go looking for supporting data you don't have yet — a statistic, a
study, a concrete example. Use it when an argument feels thin. Anything it finds is a
suggestion; the user decides whether it belongs.

For anything needing real literature depth rather than web search, hand off to
`literature-researcher`. That's an escape hatch, not a routine step.
